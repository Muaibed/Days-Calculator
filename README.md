# Days-Calculator
This project allows you to put two dates, then calculate the days between them.

## Usage

Run the script with Python 3:

```bash
python3 main.py
```

You will be prompted for a start date and an end date, both in `DD-MM-YYYY` format (e.g. `01-01-2024`). The program validates each date, including leap years, and then prints the number of days between them.
